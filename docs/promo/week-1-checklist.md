## 二、已决策（11/13）

### 1. 许可证：暂不处理

README 写 Apache-2.0、`LICENSE` 文件仍是 GPL-2.0 —— **按决定暂不动**。

> 开源后很可能被问「到底哪个」。建议备一句口径：代码按 Apache-2.0 发布，`LICENSE` 文件待更新，以 README 为准。

### 2. 注册保留（要收集用户邮箱），不做免注册体验

实测演示站邮件链路正常：

```
POST /api/v1/auth/send-code → 200 {"mail_enabled":true,"expires_in":300}
```

即陌生访客能正常收到验证码。因此改做两件降低门槛的事：

- [x] 发布稿里提前写明「需要邮箱注册」，避免评论区第一条就是"怎么还要注册"

> 「注册即带默认 Agent」不做：当前代码没有这个逻辑，不为此改动。

## 三、不做：域名 + HTTPS

决定继续用 `http://159.75.21.251:3000`，不买域名。README、Homepage、APK 的接口地址都指向它，无需改动。

已知代价（推广时需要留意）：

- 部分浏览器会对 http 页面提示「不安全」，首次打开有心理门槛
- 微信内置浏览器对 http + IP 链接可能拦截，**公众号 / 微信群分享时建议只写文字地址，不贴超链接**
- 应用商店上架需要 HTTPS 域名，即当前不满足（与"暂不上架"一致）
- 安卓端保持 `usesCleartextTraffic=true`（已配置好）
