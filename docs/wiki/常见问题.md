# 常见问题

## 部署

**后端容器反复重启，日志写 `error parsing value for field "XXX"`**
`.env` 里某个键的值类型不对，最常见是 `CORS_ORIGINS` 这类列表字段——逗号分隔和 JSON 数组两种写法都支持，但**不能留空**。另外这个变量一旦设置就会**整体覆盖**默认值，加一个来源要把所有来源写全。

**后端起不来，报数据库相关错误**
`DATABASE_URL` 留成了空串。空值会被当成真实连接串，把整行注释掉即可。

**前端能打开但接口全 502/500**
Vite 代理或 nginx 的转发目标不对。本地开发时确认后端在 `127.0.0.1:8001`，且 `vite.config.ts` 里用的是 `127.0.0.1` 而不是 `localhost`（Windows 上 `localhost` 会先解析到 IPv6）。

**改了 `.env` 不生效**
Docker 部署要 `docker compose up -d backend` 重建容器才会读新环境变量，`restart` 有时不够。

## 注册与登录

**收不到验证码**
- `MAIL_ENABLED=false` 时邮件不会真的发，验证码**打印在后端日志**里：`docker compose logs backend | grep 验证码`
- 想真正发信，要配 `MAIL_HOST` / `MAIL_USER` / `MAIL_PASSWORD` 等，并把 `MAIL_ENABLED=true`
- 内网演示可以直接 `REQUIRE_EMAIL_CODE=false`

**登录后立刻被踢回登录页**
token 过期或 `JWT_SECRET_KEY` 被改过。改密钥会让所有已发出的 token 失效。

## 知识库

**上传成功但检索不到内容**
1. 确认 `EMBEDDING_BASE_URL` 已配置（Docker 镜像不含本地 embedding 模型）
2. 查看文档详情里的分块数，为 0 说明解析失败
3. 扫描版 PDF 没有文字层，需要先 OCR

**检索结果不相关**
换中文向的 embedding 模型；或调整分块大小后重新入库。问题本身太短时，补充背景再问效果会好很多。

**换 embedding 模型后旧文档还能用吗**
不能。向量空间变了，必须重新入库。

## 模型

**怎么接本地模型**
用 Ollama 起一个 OpenAI 兼容端点，Base URL 填 `http://host.docker.internal:11434/v1`（容器内访问宿主机）。Windows / macOS 有效，Linux 需要额外配 host 映射。

**一个 Agent 能换模型吗**
能，每个 Agent 可以指向不同模型配置。贵的模型留给难任务，简单的走便宜模型。

**回答质量突然变差**
先看是不是换了模型或改了提示词；再确认知识库召回的片段是否相关——很多时候是检索的问题，不是模型的问题。

## 数据与升级

**数据存在哪**
默认 `./data/agentflow.db`（SQLite 单文件）。备份就是复制这个文件；恢复就是放回去。

**怎么升级**
```bash
git pull
docker compose up -d --build
```
数据库迁移由 Alembic 管理，启动时自动执行。升级前建议先备份 `./data`。

**能多实例部署吗**
需要 Redis 共享验证码状态，并把 `DATABASE_URL` 换成 PostgreSQL。当前编排是单实例设计。

## 其他

**支持哪些模型**
任何 OpenAI 兼容端点。非兼容协议（如部分厂商的原生 API）需要自己加适配层。

**能不能商用**
见仓库 README 的「许可证」章节。注意 `skills/` 目录下的技能来自不同社区，各自许可不同，详见 `THIRD_PARTY_NOTICES.md`。
