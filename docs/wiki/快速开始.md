# 快速开始

## 环境要求

| 依赖 | 版本 | 说明 |
|:--|:--|:--|
| Docker | 20+ | 推荐，一条命令起全部 |
| Python | 3.11+ | 仅本地开发需要，CI 基线版本 |
| Node.js | 18+ | 仅本地开发需要，CI 基线版本 |

> PostgreSQL 和 Redis 都**不是必需**的。默认用 SQLite 文件；Redis 缺失时验证码退回进程内存。

---

## 方式一：Docker（推荐）

```bash
git clone https://github.com/PHclaw/agentflow.git
cd agentflow
cp .env.example .env      # 至少填 JWT_SECRET_KEY
docker compose up -d --build
docker compose logs -f backend
```

打开 http://localhost:3000 即可。

- 默认只有两个容器：`backend`（FastAPI）+ `frontend`（nginx）
- 数据落在 `./data/agentflow.db`，`docker compose down` 不会丢
- 想切 PostgreSQL + pgvector：`docker compose --profile postgres up -d`

---

## 方式二：本地开发

```bash
# 后端
cd backend && python -m venv venv
.\venv\Scripts\Activate.ps1          # macOS / Linux: source venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8001

# 前端（另开终端）
cd frontend && npm install && npm run dev
```

前端 dev 跑在 5173，后端在 8001。注意 `frontend/vite.config.ts` 的代理默认指向 `127.0.0.1:8001`，端口被占用时用环境变量覆盖：

```bash
VITE_PROXY_TARGET=http://127.0.0.1:8002 npm run dev
```

## 方式三：SQLite 单机轻量模式

只想把后端跑起来、不想装 PostgreSQL 和 Redis：

```powershell
.\scripts\dev-backend.ps1
```

## 首次配置（必做三步）

### 1. 填 JWT 密钥

```env
JWT_SECRET_KEY=<openssl rand -hex 32 的输出>
```

不填会退化成内置明文密钥，等于任何人都能伪造登录态。

### 2. 配对话模型

登录后进「设置 → 模型配置」，填三样：**端点 Base URL、模型名、API Key**。只要是 OpenAI 兼容协议即可。

### 3. 配向量模型（知识库必需）

```env
EMBEDDING_BASE_URL=https://你的-embedding-端点/v1
EMBEDDING_MODEL=模型名
```

> **Docker 部署必须填。** 官方镜像没装 `sentence-transformers`（要加约 2GB），留空会走本地推理并失败，表现为知识库检索不可用。

## 验证清单

按顺序点一遍，能全过就算部署成功：

- [ ] `docker compose ps` 显示 backend 与 frontend 都是 Up
- [ ] 打开 `http://localhost:3000` 能看到落地页
- [ ] 能注册账号并收到验证码（或日志里能看到验证码）
- [ ] 「设置 → 模型配置」保存后，对话能收到回复
- [ ] 上传一份文档到知识库，检索能返回带相关度的片段
- [ ] Skill 广场能看到技能列表，点进去能对话

---

## 三个容易踩的坑

1. **`DATABASE_URL` 留空串会起不来** —— 空值会被当成真实连接串。不需要改就整行注释掉。
2. **Docker 部署必须填 `EMBEDDING_BASE_URL`** —— 否则知识库检索不可用。
3. **改了套餐额度要重新登录** —— 额度只在 `.env` 一处定义，登录时读取。
