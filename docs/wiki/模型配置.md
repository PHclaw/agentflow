# 模型配置

AgentFlow 只认一种协议：**OpenAI 兼容**。只要端点实现了 `/chat/completions`，就能接进来。

---

## 在界面里配（推荐）

登录后进「设置 → 模型配置」，填三样：

| 字段 | 说明 | 示例 |
|:--|:--|:--|
| 端点 Base URL | 通常以 `/v1` 结尾 | `https://api.deepseek.com/v1` |
| 模型名 | 对方文档里写的 model 值 | `deepseek-chat` |
| API Key | 令牌 | `sk-...` |

保存后**立即生效，不需要重启后端**。可以配多套，在不同 Agent 之间切换对比效果。

---

## 对话模型与向量模型是两回事

| | 对话模型 | 向量模型（Embedding） |
|:--|:--|:--|
| 用途 | 生成回复、调用工具 | 把文档切块转成向量，供知识库检索 |
| 在哪配 | 界面里 | `.env`（`EMBEDDING_BASE_URL` / `EMBEDDING_MODEL`） |
| 换掉的影响 | 回答风格与能力变化 | **已入库的向量失效，需要重新入库** |

换对话模型不会影响已有知识库；换向量模型必须重建索引。

## 常见端点

| 服务 | Base URL | 备注 |
|:--|:--|:--|
| OpenAI | `https://api.openai.com/v1` | |
| DeepSeek | `https://api.deepseek.com/v1` | 中文场景性价比高 |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | 需用兼容模式端点 |
| Moonshot | `https://api.moonshot.cn/v1` | |
| Ollama（本地） | `http://host.docker.internal:11434/v1` | 容器内访问宿主机用这个地址；Windows/macOS 有效 |

> 用 Ollama 时 Key 随便填一个非空值即可，它不校验。

## 排错

**401 / 403**
Key 错了，或者端点要求额外的 header（少数厂商要求 `Authorization: Bearer` 之外的字段）。

**连接超时**
- 容器里访问 `localhost` 指的是容器自己。要连宿主机上的 Ollama，用 `http://host.docker.internal:11434/v1`
- 本地开发时不要用 `localhost`，Windows 上会先解析到 IPv6 `::1`，一律用 `127.0.0.1`

**返回 404 / not found**
Base URL 少了 `/v1`，或者对方不支持 `/chat/completions`。

**知识库能建但不能检索**
`EMBEDDING_BASE_URL` 没配或配错。Docker 镜像里没有本地 embedding 模型，留空必然失败。

**检索结果和问题无关**
- 换更强的 embedding 模型（中文场景建议用中文向的模型）
- 文档切块太碎或太长，重新入库
- 问题本身太短，补充上下文再问
