One docker compose brings up two containers with a single SQLite file — no PostgreSQL, no Redis, no minimum hardware requirement beyond a modest VM. Swap models from the UI without a restart. Generate spreadsheets, decks and charts and get them back as downloadable attachments, previewed inline.

Two containers, one fileEverything persists in ./data/agentflow.db; back it up by copying a directory.
Models are not locked inAny OpenAI-compatible endpoint, including local Ollama. Change it live in Settings.
Real deliverablesxlsx / pptx / png come back as attachments, with images rendered inline in chat.

Quick start

Two minutes from clone to a running instance.

git clone https://github.com/PHclaw/agentflow.git
cd agentflow
cp .env.example .env      # set JWT_SECRET_KEY at minimum
docker compose up -d --build

Open http://localhost:3000, sign up, then go to Settings → Model Config and point it at any OpenAI-compatible endpoint. The demo site requires email sign-up (a verification code is sent; temporary email works).

When this fits

Honest guidance — it is not a replacement for everything.

Pick thisData must stay in your network, you have one modest server, and no dedicated ops team.
Pick DifyYou need a plugin marketplace, multi-tenancy and full observability, and have someone to run it.
Pick a desktop agentYou mostly want an assistant for one person's local files, not a shared team system.
