# 与 Dify / Coze / WorkBuddy / Codex 的差异

> 本页由 README 拆分而来，内容与代码同步维护。返回 [README](../README.md)。
>
> WorkBuddy 与 Codex 分属桌面办公智能体、终端编程 Agent 品类，和前三者「可视化 Agent 编排平台」不是同一形态；列在此处用于说明定位差异，不作同类竞品优劣比较。

| 对比维度 | AgentFlow | Dify | Coze | WorkBuddy | Codex |
|:---------|:----------|:-----|:-----|:----------|:------|
| **定位** | 零代码 Agent 编排平台 | LLM 应用开发平台 | 对话 Bot 搭建平台 | 桌面办公智能体工作台 | 终端编程 Agent |
| **协议** | Apache-2.0 | 开源（附加条款） | 闭源 | 闭源商业产品 | 开源（CLI，Apache-2.0） |
| **部署方式** | 自托管优先，默认 SQLite 单机可跑 | 自托管 / 云 | 仅云 | 桌面客户端，安装即用 | 本地 CLI + 云端沙箱 |
| **工作流编辑** | 拖拽画布 + ReactFlow | 拖拽画布 | 节点编排 | 自然语言下达任务，自动拆解执行 | 终端对话，读写代码 / 执行命令 |
| **知识库 RAG** | ✅ 内置，向量模型独立配置 | ✅ | ✅ | 本地知识库 | 以代码仓库为上下文 |
| **多模型支持** | 任意 OpenAI 兼容端点，界面热切换 | OpenAI / Claude / 更多 | 平台绑定 | 混元为主，支持多模型混合接入 | OpenAI 系为主，可配端点 |
| **数据主权** | ✅ 完全本地 | 自托管时自主 | 平台侧 | 本地执行，企业版统一管控 | 代码在本地，云端任务在沙箱 |
| **扩展方式** | `skills/` 目录 + `SKILL.md` | 插件市场 | 插件市场 | 内置技能 + 办公连接器 | MCP + 配置文件 |
| **产物交付** | 文件下载 + 图片内联预览 | 部分 | 部分 | 报告 / PPT / 表格 | 代码改动与命令执行结果 |
| **适合场景** | 自托管、数据自主、可视化编排 | 功能全面、快速上手 | 平台生态、快速验证 | 非技术角色的办公自动化 | 开发者日常编码与改库 |

**选 AgentFlow 的理由**：Apache-2.0 开源 + 默认 SQLite 单机可跑 + 数据全部落在自己的库里 + 拖拽式工作流编排 + 技能以目录形式自由扩展。

> 说明：轻量依赖集（`backend/requirements-lite.txt`）不含浏览器自动化组件；知识库向量检索默认走可配置的 embedding 端点与本地向量库，pgvector 路径仍在验证中（见 README 路线图）。
