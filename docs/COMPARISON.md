# 与同类产品的差异

> 返回 [README](../README.md)

先说结论：**AgentFlow 和下面这些产品分属不同品类**，不是同一个赛道上的替代品。
把定位摆清楚比争"谁更强"有用——选型选的是形态，不是参数。

---

## 一张表看清定位

|  | AgentFlow | Dify | Coze | WorkBuddy | Codex |
|:--|:--|:--|:--|:--|:--|
| 品类 | 可视化 Agent 编排平台 | LLM 应用开发平台 | 对话 Bot 搭建平台 | 桌面办公智能体 | 终端编程 Agent |
| 部署形态 | 自托管，默认 SQLite 单机可跑 | 自托管 / 云 | 仅云 | 桌面客户端，安装即用 | 本地 CLI + 云端沙箱 |
| 数据在哪 | 你自己的数据库 | 自托管时自主 | 平台侧 | 本地执行，企业版统一管控 | 代码本地，任务在沙箱 |
| 协议 | Apache-2.0 | 开源（附加条款） | 闭源 | 闭源商业产品 | Apache-2.0（CLI） |
| 多模型 | 界面里改，不用重启 | 需改配置后重启 | 平台绑定 | 混元为主，可混接多家 | OpenAI 系为主 |
| 扩展方式 | 加一个带 `SKILL.md` 的目录 | 插件市场 | 插件市场 | 内置技能 + 办公连接器 | MCP + 配置文件 |
| 产物交付 | 文件下载 + 图片内联预览 | 部分 | 部分 | 直接出报告 / PPT / 表格 | 代码改动与命令输出 |

## 分品类看

### 可视化 Agent 编排平台 —— Dify / Coze

**同一品类，正面可比。**

- **Dify**：功能更全、生态更成熟，插件市场、日志与观测、多租户都做得比本项目完整。代价是部署更重（PostgreSQL + Redis + worker 起步，四五个容器），对一台 2C4G 的小机器不友好。
- **Coze**：云端产品，注册即用，体验最顺。但只能用平台侧模型、数据在平台侧，私有化诉求满足不了。
- **AgentFlow**：定位是"把编排能力装进自己的机房，且不要求运维投入"。默认只有两个容器、一个 SQLite 文件；代价是功能面明显更窄（见下方"已知短板"）。

### 桌面办公智能体 —— WorkBuddy

**不是同一形态，不能互相替代。**

| 维度 | AgentFlow | WorkBuddy |
|:--|:--|:--|
| 安装位置 | 一台服务器，团队用浏览器访问 | 每个员工电脑上装一个客户端 |
| 数据位置 | 集中在一个数据库里，管理员可备份、可迁移 | 分散在各人的机器上 |
| 知识共享 | 天然共享：一套知识库里所有人可检索 | 各自本地，共享要靠额外机制 |
| 权限管理 | 有用户体系与管理员后台 | 企业版统一管控 |
| 扩展成本 | 加一个目录就是新技能，可改源码 | 内置技能 + 连接器，闭源 |
| 适合谁 | 需要**团队共用一套**、有人统一维护的场景 | 个人想让 AI 帮忙处理本机文件的场景 |

一句话：**要"每个人电脑上有个助手"选桌面端；要"团队一套系统、知识库共享、管理员管权限"选服务端。** 这两件事经常同时存在，也经常需要都上。

### 终端编程 Agent —— Codex

**完全不冲突。** Codex 解决的是"在终端里改代码"，本项目解决的是"业务同事不写代码也能用上模型"。两者可以并存：开发用 Codex，业务侧用 AgentFlow。

## 怎么选

如果你的情况是——

- 数据不能出内网，且没有专职运维 → AgentFlow 这类轻量自托管方案
- 需要成熟的多租户、插件生态、观测体系，且有运维投入 → Dify
- 只想快速验证一个对话机器人，不介意数据在云端 → Coze
- 是个人办公场景，主要处理本机文件 → 桌面客户端类产品
- 主要诉求是写代码 → 终端 Agent

## 已知短板（不藏）

选型时这些应该算进去：

| 短板 | 现状 |
|:--|:--|
| 异步任务队列 | **没有**。所有任务跑在同一条异步链路里，没有 worker 容器；长任务会占住请求 |
| 权限模型 | 只有"用户 / 管理员"两档，没有细粒度 RBAC |
| PostgreSQL 路径 | 代码支持，但**未经过端到端验证**；默认与验证过的是 SQLite + chromadb |
| 浏览器自动化 | 依赖 `playwright` / `browser-use`，默认**不安装**（体积大），需要时自行装 |
| 多实例部署 | 单实例设计。多实例需要 Redis 共享验证码状态 + 外部数据库 |
| 生态 | 没有插件市场。技能靠目录分发，社区规模远小于 Dify |
