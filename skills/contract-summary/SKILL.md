# 合同条款摘要

把一份合同变成六类关键条款清单，并且每一条都能回指原文位置。

## 适用场景 / 不适用场景

**适用**

- 快速通读采购、服务、租赁、合作等常见合同，先抓住主体、金额、付款、期限、违约与争议解决
- 需要把摘要交给同事复核，且对方要求逐条看到原文出处
- 合同里某类条款可能缺失，需要明确标出来而不是被"常见模板"补齐

**不适用**

- 需要法律意见、风险评级或条款效力判断（本技能只做事实摘要）
- 扫描件只有图片、没有文字层（无法抽取文本）
- 需要修订合同或生成新合同文本

## 输入要求

任选其一：

- **PDF**：上传带文字层的 PDF；页数不限，2 页以上效果更明显
- **Word**：上传 `.docx` 文件
- **纯文本**：直接粘贴合同正文；有条款编号、页码或段落分隔更好

最好再补一句关注点（例如"重点看付款与违约责任"）；没有也可以直接提交。

## 输出格式

固定输出六类，每类至少一行：

| 条款类型 | 内容摘要 | 原文出处 |
|:--|:--|:--|
| **主体** | 合同双方名称、签署主体或身份信息 | 第 X 页第 Y 段 / 第 N 条 |
| **金额** | 合同总价、单价、币种、含税口径 | 第 X 页第 Y 段 / 第 N 条 |
| **付款方式** | 付款节点、比例、账期、支付方式 | 第 X 页第 Y 段 / 第 N 条 |
| **期限** | 生效日、有效期、交付或续约期限 | 第 X 页第 Y 段 / 第 N 条 |
| **违约责任** | 违约情形、违约金或赔偿计算方式 | 第 X 页第 Y 段 / 第 N 条 |
| **争议解决** | 协商、仲裁或诉讼及管辖约定 | 第 X 页第 Y 段 / 第 N 条 |

同类条款出现多处时分行列出，不合并成一句含糊表述。找不到时写 `未找到`，出处列写 `—`；完全无法定位但内容存在时，出处列写 `原文位置无法定位`。

## 处理步骤

1. **抽取文本**：读取上传文件或粘贴内容；扫描件先确认是否有文字层。
2. **分节**：按条款编号或主题把文本切成主体、金额、付款方式、期限、违约责任、争议解决六组。
3. **提炼**：逐组写短句摘要，保留数字、日期、主体名称原文，并记录出处。
4. **自检遗漏**：逐项核对六类是否齐全；缺项写 `未找到` 并进入「遗漏与待确认」，不凭常识补齐。

输出结构依次为：`摘要范围` → 条款表格 → `遗漏与待确认` → `风险提示（非法律意见）`。

## 边界条件

- **合同里没有金额条款**：金额行写 `未找到`，不要写"金额待定""按双方约定"或自行估算。
- **扫描件没有文字层**：直接说明无法生成摘要，提示改用带文字层的 PDF / Word 或粘贴文本；不要根据文件名或封面推测内容。
- **多处条款互相矛盾**：分行如实列出并标注各自出处，不替用户判断哪一条有效。
- **只有片段而非完整合同**：在「摘要范围」里说明材料不完整，未出现的条款一律写 `未找到`。
- **金额同时有大小写**：两种写法并列保留，不自行换算币种或纠正数字。

## 示例触发语

- "总结这份合同的六类关键条款，标出原文出处"
- "帮我看一下这份采购合同的付款方式和违约责任"
- "这份协议里有没有争议解决条款？没有就写清楚"
